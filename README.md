# Emil Kurian - Portfolio

Portfolio website built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**.

## Getting Started

### Install Dependencies

```bash
bun install
```

### Run the Development Server

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
bun run build
```

### Preview Production Build

```bash
bun run preview
```

### Linting

```bash
bun run lint
```
